# 单词守卫 Word Guard

面向小学三年级左右孩子的英语单词塔防小游戏。Web 版先行，代码按"规则 / 平台 / 画面"三层拆开，之后接 iOS、Android、微信或抖音小游戏时只需换掉外面两层。

## 怎么玩

小怪举着画了东西的牌子，从田野那头走向你的小屋。

- **听音关**：游戏读出一个单词（部分关卡同时显示英文），孩子点举着对应图片的小怪，小屋发射星星把它打倒。
- **拼写关**：离小屋最近的小怪被锁定，孩子用字母块拼出它举着的东西。

英语就是操作本身，没有"先答题、再玩游戏"的环节。

| 规则 | 设计原因 |
| --- | --- |
| 点错的小怪会往前冲一段，同一题错得越多冷却越长 | 让乱点比认真听更容易输 |
| 连错两次后高亮正确的小怪 | 卡住的孩子能继续，但这题不算"一次就对" |
| 听音关同屏至少两只小怪才出题 | 只有一个选项时不用听也能点对 |
| 星星看"一次就答对"的比例，不只看剩几颗心 | 不让"乱点等提示"拿满星 |
| 漏掉的词会弹出"刚才那个是 🍊 orange"并读一遍 | 错误立刻变成一次学习 |

共 3 个主题（果园、动物园、小镇）、32 个词、9 关，最后一关"大复习"优先出最容易错的词。

## 运行

```bash
npm install
npm run dev      # 本地开发
npm test         # 单元测试 + 模拟玩家难度检查
npm run build    # 生成 dist/index.html（单文件）和 dist/word-guard.html（发布用片段）
python3 scripts/playtest.py dist/index.html shots/   # 无头浏览器自动试玩并截图（需要 Playwright）
```

## 目录

```
src/
  core/                 纯 TypeScript 规则，不依赖任何引擎或平台
    content/words.ts    词库（单词、中文、图片占位、主题）
    content/levels.ts   关卡参数（模式、速度、数量）
    learning/engine.ts  学习引擎：记忆盒、选词、掌握度、存档校验
    battle/battle.ts    战斗规则：出怪、出题、判定、扣心、胜负、星星
    session.ts          把战斗和学习引擎接起来
  platform/
    types.ts            平台接口：存储、发音、音效
    web.ts              Web 实现：localStorage、Web Speech、Web Audio
  game/                 Phaser 4 画面层：场景、布局、小怪、按钮
tests/                  单元测试 + 模拟玩家
scripts/                字体字表生成、发布片段生成、自动试玩
```

规则层每帧被画面层调用 `update(dt)`，画面层通过 `drainEvents()` 拿到事件（出怪、出题、打倒、点错、漏掉……）再播动画和声音。规则层不知道屏幕、像素和按钮的存在，所以横竖屏切换时战斗可以无损接上。

## 接其他平台

| 平台 | 要做的事 |
| --- | --- |
| iOS / Android App | 用 Capacitor 打包现有 Web 构建；`platform/` 下新增一份实现，存储换成 Preferences，发音换成预录音频 |
| 微信 / 抖音小游戏 | `platform/` 新增实现（`wx.setStorage`、`InnerAudioContext`）；画面层需要小游戏适配器，或把 `game/` 换成官方支持小游戏的引擎重写。`core/` 不用动 |
| 云同步 / 家长账号 | 在 `platform.storage` 后面接服务端；存档已经带版本号和校验 |

## 学习引擎

- 每个词分两项技能记录：**认得**（听/看 → 图）和**会拼**。
- 采用 Leitner 记忆盒 0–5：一次就对升一盒；错过后做对降一盒；没做出来清零。下次复习间隔为 0 / 10 分钟 / 1 天 / 3 天 / 7 天 / 16 天。
- 选词权重：到期且不熟的词最高，新词适中，没到期的熟词最低；同屏的词互不相同，刚出过的词尽量不连着出。
- 单词本显示每个词的两项掌握度，点卡片可以听发音。

## 难度是怎么定的

`tests/battle.test.ts` 用不同类型的模拟玩家把每关各打 20 局：

- 认真的孩子（2.5 秒反应、85% 正确）：每关至少赢 19 局，平均 2 星以上；
- 慢但准的孩子（3.5 秒反应、90% 正确）：每关至少赢 16 局；
- 乱点等提示：听音关平均不超过 1.5 星。

这组测试在开发中发现过两个真问题：最初纯乱点能全胜；只有一只小怪时出题，不用听就能点对。两处都已修正，测试会防止它们回来。真实孩子的反应时间要靠试玩数据校准。

## 已知限制

- 图片暂用系统 emoji，不同设备长相不同；正式版需换成原创插画（只改 `words.ts` 的 `picture` 和小怪牌子的绘制）。
- 发音用浏览器自带语音，音质随设备变化；没有语音的环境会自动显示英文单词兜底。正式版建议预录真人发音。
- 字体从 Google Fonts 加载，中文只请求游戏里用到的字；加载失败时用系统字体。中国大陆正式上线需改为自托管字体。
- 学习记录只存在本机浏览器里。
