# 单词守卫 Word Guard

面向小学三年级左右孩子的英语单词塔防小游戏。Web 版先行，代码按"规则 / 平台 / 画面"三层拆开，之后接 iOS、Android、微信或抖音小游戏时只需换掉外面两层。

## 怎么玩

小怪举着牌子，从田野那头走向你的小屋。打倒它们靠英语：

- **听+看 / 纯听**：游戏读出英文（"听+看"同时显示英文），孩子点举着对应图片或中文意思的小怪。
- **认英文**：显示中文意思，孩子点举着对应英文的小怪；打倒后读一遍发音。
- **拼写**：离小屋最近的小怪被锁定，孩子用字母块拼出它举着的东西。

| 规则 | 设计原因 |
| --- | --- |
| 点错的小怪会往前冲一段，同一题错得越多冷却越长 | 让乱点比认真听更容易输 |
| 连错两次后高亮正确的小怪 | 卡住的孩子能继续，但这题不算"一次就对" |
| 同屏至少两只小怪才出题；同屏的词意思和图片都不重复 | 只有一个选项时不用听也能点对；sweater/jumper 这种同义词同时出现会有两个正确答案 |
| 星星看"一次就答对"的比例，不只看剩几颗心 | 不让"乱点等提示"拿满星 |
| 小屋上方的城堡血量条，每溜进一只小怪少一格 | 孩子一眼看到还剩几次机会 |
| 漏掉的词会弹出"刚才那个是 orange 橙子"并读一遍 | 错误立刻变成一次学习 |

## 课程

首页两条路线，共用一套词库和学习记录（同一个英文词只有一条，在课本里学会了，剑桥路线里就算复习）：

- **剑桥路线**：Starters（39 单元）→ Movers（35 单元）→ KET（90 单元）→ PET（85 单元）。
  - **Starters / Movers**：剑桥少儿英语 Pre A1 Starters、A1 Movers 2018 词表里的实词（去掉代词、介词、情态动词、人名等），按主题分单元（身体、颜色、数字、水果……），每单元 6–10 词。词表来自 [ozbonus/cambridge-english-test-vocabulary](https://github.com/ozbonus/cambridge-english-test-vocabulary)（CC BY-SA 4.0，整理自剑桥官方 PDF），中文释义和配图由 Claude 整理，`content/yle-*.txt` 同样按 CC BY-SA 4.0 提供。
  - **KET**：剑桥 A2 Key 官方词表里的实词共 1446 个（去掉了冠词、代词、连词、情态动词、感叹词、缩写；英美拼写取美式），按难度从易到难排成 90 个单元、每单元 16 词。
  - **PET**：剑桥 B1 Preliminary 2025 年 8 月版词表（约 3100 个词条）里，去掉 KET、启蒙、课本已有的词和功能词后剩下的 1360 个实词，英式拼写改成美式（colour → color、centre → center），按难度排成 85 个单元、每单元 16 词。每个词配了一句例句，第 3 步是"例句填空"：面板显示挖空的句子和中文意思，孩子点能填进去的英文，打倒后把整句读一遍。PET 抽象词多，只有约 6% 有图。词表从剑桥官方 PDF 整理，释义、配图、例句由 Claude 编写，在 `content/pet-*.txt`（第 4 列是例句），改完运行 `python3 scripts/build-ket.py pet`。
- **上海课本**：一至五年级上下册，每册按课本单元分（太小的单元合并、太大的拆开，每单元 6–12 词）。上海小学英语正在换新教材（2024 年起分年级启用新编《英语》和五·四学制《英语》，原"牛津上海版"退出目录）。目前一上、一下、三上、四上用的是新版单元词表；二上、二下、三下、四下、五上、五下暂用旧版牛津上海版的 Module 词表，游戏里标"旧版"。拿到新版词表后替换对应的 `content/sh-*.txt` 即可。课本词按美式拼写收录（colour → color、mum → mom、lorry → truck），和全游戏的美音发音一致。
- **每单元的几步**：

  | 课程 | 第 1 步 | 第 2 步 | 第 3 步 | 第 4 步 | 城堡血量 |
  | --- | --- | --- | --- | --- | --- |
  | Starters、一二年级 | 听+看 | 纯听 | 看图选英文 | 补字母（挖掉约 1/3） | 4 |
  | Movers、三四年级 | 听+看 | 纯听 | 认英文 | 补字母（挖掉约 1/2），第 5 步听写补字母 | 3 |
  | KET、五年级 | 听+看 | 纯听 | 认英文 | 整词拼写，第 5 步听写 | 3 |
  | PET | 听+看 | 纯听 | 例句填空 | 整词拼写，第 5 步听写 | 3 |

  **听写**：小怪牌子上只有问号，面板上只有喇叭，只听发音拼出单词（设备读不出声音时退回普通拼写）。

  小朋友的关卡怪物更慢、同屏最多 3 只。能拼的词（单个词、2–8 个字母）少于 4 个的单元没有拼写步。
- **数字**：one–twenty、thirty–hundred、序数词 first–twentieth 的"图"直接画成数字（`txt:12`、`txt:3rd`）。
- **词表文件**：KET 在 `content/ket-*.txt`（`英文|中文|图片`），改完运行 `python3 scripts/build-ket.py`；KET 单元按难度排序：常用程度（wordfreq 的 Zipf 值）+ 能画出来的具体名词更容易 + 长词更难。启蒙和课本在 `content/yle-*.txt`、`content/sh-*.txt`：`## 单元名` 下每行一个词，只写英文表示沿用已有释义，写成 `英文|中文|图片` 表示在这里第一次定义；`npm run build` 会自动运行 `scripts/build-courses.py` 生成 `courses.ts` 并校验。
- **解锁**：单元里上一步过关开下一步；剑桥路线上一单元"纯听"过关开下一单元，每门课（Starters / Movers / KET）的第 1 单元都开放，水平测试建议的起点之前全部开放；上海课本所有单元都开放，跟着学校进度点。选关页的"选级别 / 选年级"可以直接跳到某门课。
- **今日复习**：学过、到期、最不熟的词凑够 8 个就出现在选关页右上角；每天第一次进选关页会问一次"先复习一下？"。
- **单元里混旧词**：单元第 2 步起的听音、认英文类关卡，大约每 5 题混进 1 个别的单元里到期的旧词（最多 4 个不同的），复习不用专门进复习关（`core/session.ts` 的 `reviewExtras`）。
- **水平测试**：24 道"看英文选中文"，可以选"不认识"。前 8 题答对就升一级，之后连对 2 题升一级，答错降一级；最后用全部 24 题算最可能的水平（Starters / Movers / KET 五段 / PET 三段，共 10 段），给出剑桥路线的起始单元，答错的词记进复习。模拟测试里 30 次最多 1 次偏差超过 1 段。旧存档的测试结果会自动换算。
- **释义**：1446 条中文释义由 Claude 整理，2026-11-07 家长核对后修改了 197 条（多为补充多个意思，如 right：正确的；右边；向右）。词表来源是剑桥公开的 A2 Key 词表，商业使用前要确认授权。
- **配图**：3112 个词里 841 个有图。大多数是系统 emoji；emoji 里没有的具体东西（橡皮、书柜、洗衣机、扶手椅、耳环、露营地等 66 个）用开源矢量图标，在词表里写成 `icon:图标集:名字`。规则：同一张图只能给同义词共用（如 shop/store）；不用图上本身写着英文的 emoji（🆕、🔙 这类等于把答案写出来）；孩子容易认成别的东西的不配（比如 small 配蚂蚁、passenger 的图标像轮椅）。看起来很像的图（🐶/🐕、💻 和笔记本图标等，见 `words.ts` 的 `LOOKALIKE`）不会同屏出现。启动时检测设备能否显示每个 emoji（红蓝两色各画一遍，彩色字形不随笔色变），显示不出的自动改成显示中文。剩下没图的主要是抽象词、月份星期、亲属称呼等画不出来的词。
- **图标**：来自 [Iconify](https://iconify.design/) 的三个图标集——Material Design Icons（Apache 2.0）、Material Symbols（Apache 2.0）、game-icons.net（CC BY 3.0，要求署名，图鉴页底部已注明）。`npm run build` 时 `scripts/build-icons.mjs` 只把词表用到的图标抽出来写进 `src/game/icon-data.ts`（约 34 KB），不需要联网。图标是单色的，游戏按名字给每个图标分配一种鲜艳颜色，启动时画成贴图（`src/game/pictures.ts`），所有画图的地方都走 `addPicture`。
- **单元划分固定**：`build-ket.py` 会沿用已发布的单元，只更新释义和图片；新加的词放进最后的新单元。这样改词表不会打乱孩子的星星和进度。
- **多义词**：释义用"；"分隔多个意思。小怪牌子和测试选项只显示前一两个意思（不超过 7 个字），图鉴、结算页、漏词提示显示完整释义。同屏的词只要有一个意思相同就不会同时出现，避免一题两个正确答案。

## 一题一次机会（防乱点）

孩子试玩反馈：乱点也能靠排除法过关。原因是点错几乎没代价（冷却不到 1 秒、不扣心），连错两次还会高亮答案。现在的规则（`core/battle/battle.ts`）：

- **先教再考**：没见过的词第一次上场时战斗停一下，弹"新词"卡片（图 + 英文 + 中文 + 读音），点一下或读完自动关。
- **点击类（听音、认英文、例句填空）一题只有一次机会**：点错 → 揭示正确答案并再读一遍 → 扣半颗心 → 被问的小怪溜走，至少 6 秒后回来再考。回来那次答对只记"错过后做对"，不算一次答对。
- **拼写按要填的字母数给机会**（1 个字母 1 次，2 个 2 次，之后每多 2 个多 1 次，最多 5 次）：点错字母、用"提示"都占一次；用完 → 揭示拼法、扣半颗心、溜走再来。只剩最后一次机会时不给提示。
- **始终 3 个选项**：点击类凑够 3 只才出题；真怪出完了来"看热闹的"小怪凑数（不会被问、不扣心，走到门口或过关时自己跑掉）。
- 小怪进家门仍扣一整颗心。星星看"第一次就答对"的比例（回来再考的不算）。
- 模拟玩家（`tests/battle.test.ts`，每关 20 局）：乱点总胜率不到 6%、拼写类一局都赢不了；只认识四分之一的孩子在大孩子的关多数过不了；85% 正确率的孩子每关几乎必过、平均 2 星以上。

## 即时反馈

- 每打倒一只：命中光圈、碎屑、轻微震屏、手机震动（安卓），飘出"+分数"飞到右上角入账。分数 = 一次答对 100（回来再答对 50）+ 连击每多 1 次 +10（封顶 +100）+ 3 秒内答对 +50。
- 连击 2 次以上，战场上方常驻"连击 ×N"，越高字越大、音调越高；3 / 5 / 8 / 12 / 16 / 20 连击有大字播报、闪光和彩纸。
- 点错、漏怪：红闪、心碎裂、被点的小怪头上写"✗ 这是 xxx"，正确的那只亮起来写"✓ xxx"。
- 结算页：分数滚动累计（答题 + 剩下的心每半颗 50 + 全部一次答对 300），显示最高连击；破了本关纪录盖"新纪录！"。每关最高分存在存档的 `levels[关].best`。

## 激励（让孩子愿意天天回来）

规则都在 `core/rewards.ts`，画面在 `game/scenes/`。存档只多了 `xp`（累计经验）和 `daily`（今天宝箱开没开），其余都从已有的学习记录里算。

- **图鉴**（原来的单词本）：每个词一张卡。"认得"到了眼熟就点亮 ✓，"会拼"到了眼熟升级成金卡 ★。顶上写已收集几张、金卡几张；结算页提示"图鉴 +N / 金卡 +N"；地图上点开一个单元能看到这个单元收集了多少。
- **每日任务 + 宝箱**：每天三个小目标——守住一关、一次答对 20 题、打出一次 5 连击（按当天的游戏记录算）。三个都完成，首页的按钮变成"开宝箱！"，开出 300 经验，一天一次。连续学习天数（某天答了 3 题以上算学过）也显示在这个按钮上。
- **段位 + 城堡成长**：每局的得分就是经验（输了只算答题分）。10 个段位：见习守卫 → 小卫兵 → 卫兵 → 骑士 → 大骑士 → 队长 → 将军 → 英雄 → 传奇守卫 → 守卫之王，前几级升得快。每升两级，孩子守的家换个样子：小木屋 → 带旗子的木屋 → 石头塔楼 → 城堡 → 金顶大城堡（`ui/castle.ts`），战场上和首页"段位"面板里都看得到。
- **单元 Boss 战**：每个单元最后多一关。只听声音，用这个单元的全部词；每打倒一只小怪 Boss 掉一格血，打到一半 Boss 狂暴、小怪提速 30%，打完 Boss 炸成一片星星。前面几步都过关后才出现，打过了地图上那一站戴皇冠。
- **连击换技能**：每次一次答对攒 1 点能量，攒满 5 点左下角的"冰冻"按钮亮起，点一下全场小怪停 6 秒。答错不清空能量，但不涨。
- **输了的缓冲**：失败页的主按钮是"复习错词再战"——把这局错的词（最多 5 个）一张张过一遍（图 + 英文 + 中文 + 读音），然后带一面护盾重开，护盾挡掉第一次扣心。
- **地图式选关**：每页是一张地图，单元是小路上的一站，"到这啦"的小旗指着现在该打的那站；点一站弹出这个单元的几步、Boss 战和图鉴进度。
- **装扮**：每"认识"50 个词解锁一种小怪装扮，共 10 种（小红帽、蝴蝶结、小花、墨镜、魔法帽、耳机、皇冠、围巾、小犄角、宇航头盔）。画法在 `ui/monster.ts` 的 `drawOutfit`。
- 升级、单元全部过关、解锁新装扮时，结算页撒彩纸庆祝。

## 节奏、花样和家长功能（2026-11-16）

- **"继续"按钮**（`core/progress.ts` 的 `continueTarget`）：玩过的孩子首页中间是一个大的"继续"，一点就进下一关——今天还没复习且攒够了到期的词就先复习，否则接着上次那条路线、上次那个单元往后第一个没过的关。新玩家没有这个按钮。
- **局内自适应节奏**（`battle.ts` 的 `PACE`）：每答完一题调一次。连续 4 题又对又快（点击类 3 秒内）提速 6%，最多到 1.24 倍；答错、拼不出、漏怪立刻降 10%，最低 0.78 倍，场上已有的小怪也跟着慢下来。只改速度和出怪间隔，不改题目和扣心。慢但准的孩子保持原速。
- **小怪种类**（`VARIANTS`）：快跑怪（快 32%，个头小，一次答对 +40）、大块头（慢 20%）、金色怪（约 6%，一次答对 +200）。"听+看"第一步不出；拼写类只偶尔出金色的。
- **景色**（`theme.ts` 的 `FIELD_THEMES`）：草地、森林、沙滩、雪地、傍晚，每两个单元换一种，Boss 关固定傍晚。只换颜色和地上的点缀。
- **听写练习**（`levels.ts` 的 `dictationLevel`）：地图上点开任何单元，最下面有"听写练习"。只听发音、整词自己拼，这个单元能拼的词每个考一次（最多 14 个），5 颗心、走得慢。不用解锁、不算单元进度——给"明天学校听写这个单元"用。
- **本周小结**（`game/report.ts`）：学习记录页左下角。画成一张图：7 天里学了几天、多少分钟、练了多少词（新学多少）、一次答对率、每天分钟数、累计认得/会拼、还不熟的词、接下来学什么。家长长按保存或点"保存 / 分享"发家庭群。图上不写孩子名字。新增统计事件 `week_report`。
- 存档里每个词多记一个第一次遇到的时间（`first`），用来算"本周新学"；旧存档里的词没有这项，第一周的"新学"会偏少。

## 养成小伙伴（2026-11-16）

规则在 `core/rewards.ts`（`PET_KINDS`、`PET_STAGES`、`petState`、`petPerk`），样子在 `game/ui/pet.ts`（全用图形画，三种 × 六个阶段），起名字在 `game/pet-name.ts`。

- **领养**：首页正中间有一颗蛋，点它从三颗里选一颗——会孵出小龙、小狐或小猫头鹰。选了不能换。
- **怎么长大**：只看图鉴。点亮一张卡（认得）+1 点，升成金卡（会拼）再 +1 点。六个阶段：蛋 → 宝宝（3 点）→ 小不点（30）→ 少年（100）→ 大伙伴（250）→ 传说伙伴（600）。和玩了多久、连续几天无关，也不会变小——**没有"不喂就饿、不来就难过"这类惩罚**。
- **起名字**：孵出来时请孩子起名（最多 8 个字），之后可以在小伙伴面板里改。名字只存在本机进度里，不进统计。
- **在哪出现**：首页中间（点它看面板：现在的样子、下一个样子的剪影、成长条、本领）；战斗时站在家旁边，答对了跳一下，家被打了缩一下；结算页长大时有专门的庆祝（旧样子缩下去、新样子蹦出来）。
- **本领**（小帮手，不改变"认识才过得了关"）：小不点开局带 1 点冰冻能量，少年 2 点，大伙伴 2 点且冰冻多 2 秒，传说 3 点且冰冻多 2 秒。
- 存档多一项 `pet: { kind, name?, at }`；长到哪个阶段是算出来的，不存。统计事件：`pet_adopt`（种类）、`pet_grow`（种类、阶段）、`pet_named`（不带名字）。

## 界面素材：插画为主，图形画兜底（2026-11-16）

- **插画素材**放在网站仓库的 `art/ui/`（清单 `art/ui/index.json`），和单词插画同一套画风：13 个图标（火苗、任务板、城堡、蝴蝶结、礼物、锁、皇冠、铅笔、Boss 头像、闪电、雪花、星、宝箱）、5 个阶段的家、Boss（平时 / 狂暴）、3 种小伙伴 × 6 个阶段（含蛋）、应用图标，共 39 张。

- 界面上不再用系统 emoji（不同手机长得不一样，老手机还可能是方框）。

- **反馈问题或需求**（首页"反馈"、学习记录页）：测试者选类型（遇到问题 / 想要的功能 / 内容有错 / 其他）、写描述、可留联系方式，默认附上设备、版本、学习汇总和最近 20 局明细，通过 Formspree 发到开发者邮箱（`src/game/feedback.ts` 的 `FEEDBACK_ENDPOINT`）。每台设备有个匿名测试者编号，方便把同一个人的反馈对上。地址没设置或发送失败时，改成"复制反馈"让测试者发微信。
- "备份进度"把整个学习档案压缩成一串以 `WG1.` 开头的文字（`src/game/backup.ts`），换设备或清缓存后在"恢复进度"里粘贴回来。复制、粘贴用网页原生对话框（`src/game/ui/dialog.ts`），因为 iPhone 只在真实点击时允许写剪贴板。

## 国内访问和离线

- 字体不再从 Google Fonts 加载（国内打不开，每次启动白等）：`scripts/fonts.py` 从 npm 包 @fontsource/zcool-kuaile、@fontsource/baloo-2 里只取界面用到的约 350 个汉字和英文字母，打包进游戏（约 80 KB）。需要 `pip install fonttools brotli`。

## 插画

- **画风统一，表达方式随理解能力递进**（`src/core/content/art.ts`）：启蒙 Starters 突出单个物体和动作 → Movers 加入简单关系 → KET 用日常情境 → PET 用清晰的情境表达较抽象的词。上海课本按年级并入：一二年级算 Starters，三四年级算 Movers，五年级算 KET。
- **手机小图可辨认**：游戏里图片常常只有 60~120 像素，所有阶段都用近景、主体占满画面、最多两个大元素，不画房间和远景小人。KET 用近景特写加一个日常道具，PET 用半身夸张表情加一个因果符号。自动检查也会把小图看不清的判为不合格。
- **跨阶段的词**（678 个；不算数字字母和功能词共 693 个）：词义和教学情境一致时复用前一阶段的图（多是具体名词），否则每个阶段各画一张，所以最终图数会超过词数。游戏里每个关卡按课程所在阶段取图；某阶段没有自己的图就用更早阶段最近的一张；图鉴用最早学到时的图。插画清单的键是"词@阶段"。
- **范围**：构建时 `scripts/art-targets.py` 列出 2993 个词（不画数字字母 48 个和冠词、代词、介词、连词等功能词 71 个），每个词带中文意思、出现的所有阶段、例句（PET 例句、多音词语境句），共 3818 个"词×阶段"。部署时复制成网站仓库的 `art/targets.json`。
- **生成**：网站仓库的 GitHub Actions"生成插画"（`tools/art.py`），走 Google Vertex AI（Google Cloud 的 $300 试用金不能付 AI Studio 里 Gemini API 的费用）。Secrets：`VERTEX_API_KEY`，密钥绑定了项目时再加 `GCP_PROJECT`。分两步：
  1. 规划：文字模型（`gemini-3.5-flash`，不可用时自动换）给每个"词×阶段"写一句画面描述，并判断跨阶段的词哪些阶段复用，写 `art/plan.json`。`art/hints.json` 可以手写 `{"词@阶段": "画面描述"}` 覆盖。
  2. 画图：Nano Banana 2（`gemini-3.1-flash-image`，512 尺寸约 $0.045/张）按描述画。`art/style/` 里放 2~3 张挑好的图作画风参考，每次请求都带上。
  3. 自动检查：文字模型看每张图有没有文字、能不能看出词义；不合格的按它建议的新画面重画一次，还不行就在审核页标红（`art/flags.json`）。
  图像模型先用 Nano Banana 2.1（`gemini-nano-banana-2.1`，1K 约 $0.034/张），不可用时换 Nano Banana 2（512 约 $0.045/张）。
  模式：sample（16 个词，含跨阶段的）、plan（只规划，几美元）、full（全部，每 150 张提交一次；一个任务跑满 5 小时就停，再触发接着画）、redo（"词" 或 "词@阶段"）。
- **花费**：按 Google 返回的实际 token 数和官方价格累计在 `art/spend.json`，到上限（默认 $250）自动停。预计规划约 $6、画图最多约 $150、检查约 $10、自动重画约 $30，合计约 $195。
- **结果（2026-11-12 画完）**：3608 张图（约 60 MB），覆盖 3682 / 3818 个"词×阶段"，2881 / 2993 个词有图；112 个词不用图（星期、月份、方位、讲文字本身的词、太抽象的词，以及自动检查两次没过的），游戏里显示文字。总花费约 $207（规划 $6、画图 $177、检查 $24），用的是 Google Cloud 试用金。自动续画已关（`art/autopilot.json`）。
- **端点和检查**：走 global 端点（价格最低，Nano Banana 2.1 只在 global），项目号写在 `art/run.json` 的 `project`（或 Secrets 的 `GCP_PROJECT`）。check 模式只调 countTokens（Google 不收费），检查密钥和各模型能不能用。
- **自动触发**：推送 `art/run.json`（如 `{"mode": "full", "n": 3}`，n 每次加 1）就会运行，不用打开 GitHub 网页。每次运行写 `art/status.json`（结果 done / more / stopped / error、进度、花费、出错信息），失败也会提交，可以用 git 拉下来看。
- **审核**：`art/review.html` 每行一个词，按阶段从左到右，显示图和画面描述、哪些阶段复用。不通过的放进 `art/reject.json`（"词" 或 "词@阶段"），游戏不用。
- **游戏**：启动时读 `art/index.json`，有插画的词用插画代替 emoji/图标（`art:文件名`），进关卡时预先下载，没下好先放透明占位、下好再换上。`complete: true`（全部画完）以后，没有插画的词也不再显示 emoji，避免画风混在一起。

## 声音

- **单词朗读（录音）**：全部单词和 PET 例句整句（约 4470 条、6 万字符）用 Google Cloud Text-to-Speech 预先生成 MP3，放在网站仓库的 `audio/`。构建时 `scripts/audio-texts.py` 列出要读的文字（`dist/audio-texts.json`），部署时复制成网站仓库的 `audio/texts.json`；网站仓库的 GitHub Actions"生成发音"（`tools/tts.py`，密钥放在仓库 Secrets 的 `GOOGLE_TTS_API_KEY`）只生成还没有的录音，并写 `audio/index.json`（文字 → 文件名）。sample 模式生成试听页 `audio/samples.html` 用来挑声音。2026-11-08 选定 Chirp 3 HD 的 Leda、语速 1.0，4470 条全部生成（约 32 MB，单词平均 1 秒）。部署时 `audio/texts.json` 有变化会自动触发补录，只生成新增的；Chirp 3 HD 限每分钟 200 次请求，脚本已限速并支持失败后续跑。
- 游戏启动时读 `audio/index.json`；有录音的直接用 Web Audio 播放（和背景音乐同一个声音通道），进关卡时预先下载本关要读的录音。没有录音（还没生成、离线、在别处打开）时退回浏览器自带朗读：iOS Safari 只允许在用户点击的那一刻开始朗读，所以平台层在第一次点击时用原生事件解锁声音并"预热"朗读。设备没有英文语音、或连续两次读不出来时，自动把单词显示出来，游戏照样能玩。
- **背景音乐**：现场合成，不需要音频文件。菜单和暂停时只有轻柔的和弦，战斗时加低音，有小怪快到家门时加鼓点。音乐一直在放；读单词前用 0.2 秒把音乐压低到 15%，读完 0.2 秒抬回来，像听歌时插入语音（`DUCK_LEVEL`、`DUCK_FADE`）。连着读几个词时中间保持压低。Phaser 自带音频已关闭，全游戏只用一个 AudioContext。
- **iPhone 读词后音乐消失**：系统朗读结束后，网页声音通道有时会被挂起，或者显示在运行却没声音。处理：挂起时自动恢复；iPhone 上每读完一个词，下一次点屏幕时整个重建声音通道（iOS 只允许在点击时做）。"试听发音"的结果里会显示声音通道状态和刷新次数，方便远程排查。
- 菜单右上角可以分别关掉音乐和音效，单词朗读始终保留。
- **iPhone 注意**：手机侧边静音键打开时，网页（包括朗读）没有声音，要先关掉静音键。网页声音不能设成"独占播放"，否则系统朗读会被挤掉、读一半就断。
- 游戏自动出的词会排在正在读的词后面，不会互相打断；孩子主动点喇叭时才立刻重读。
- 菜单左上角"试听发音"会读 apple 并显示是否成功，用于远程排查。

## 学习引擎

- 每个词分两项技能记录：**认得**（听/看 → 图）和**会拼**。
- 采用 Leitner 记忆盒 0–5：一次就对升一盒；错过后做对降一盒；没做出来清零。下次复习间隔为 0 / 10 分钟 / 1 天 / 3 天 / 7 天 / 16 天。
- 选词权重：到期且不熟的词最高，新词适中，没到期的熟词最低；同屏的词互不相同，刚出过的词尽量不连着出。
- 图鉴里每张卡显示这个词的两项掌握度，点卡片可以听发音。

## 难度是怎么定的

`tests/battle.test.ts` 用不同类型的模拟玩家把每关各打 20 局：

- 认真的孩子（2.5 秒反应、85% 正确）：每关至少赢 19 局，平均 2 星以上；
- 慢但准的孩子（3.5 秒反应、90% 正确）：每关至少赢 16 局；
- 乱点等提示：听音关平均不超过 1.5 星。

这组测试在开发中发现过两个真问题：最初纯乱点能全胜；只有一只小怪时出题，不用听就能点对。两处都已修正，测试会防止它们回来。真实孩子的反应时间要靠试玩数据校准。

## 已知限制
