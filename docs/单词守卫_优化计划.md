## 2026-11-12：让孩子愿意坚持玩的 7 项（全部上线）
1. **图鉴**：单词本改成收集册，认得点亮 ✓、会拼变金卡 ★；结算页提示新收集了几张
2. **每日任务 + 宝箱**：守住一关 / 一次答对 20 题 / 打出 5 连击，全完成开宝箱 +300 经验
3. **段位 + 城堡成长**：得分即经验，10 个段位（见习守卫 → 守卫之王）；每升两级家换个样子（小木屋 → 金顶大城堡）
4. **单元 Boss 战**：每单元最后一关，只听声音、全单元的词，Boss 掉血、半血狂暴
5. **连击换技能**：一次答对攒能量，满 5 点可放"冰冻"停住全场 6 秒
6. **输了的缓冲**：失败页"复习错词再战"，过一遍错词卡片后带护盾重开
7. **地图式选关**：单元变成小路上的一站，点开看几步、Boss 和图鉴进度
- 说明：老存档的经验从 0 开始算（以前没记得分）；已经"单元完成"的单元现在多了一关 Boss 才算完成
- 待观察：段位升得快慢、每日任务难不难、Boss 关过关率（看"学习记录"和反馈），数值都在 `core/rewards.ts` 和 `core/battle/battle.ts` 顶部
